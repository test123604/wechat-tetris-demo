# WeChat Tetris Demo

基于 Cocos Creator 的微信小游戏俄罗斯方块练习项目。

## 目录

- `Tetris/`：游戏脚本、场景、音频与资源。
- `OpenDataDomain/`：微信小游戏开放数据域示例。

## 当前状态

历史学习项目，本次未启动 Cocos Creator 或微信开发者工具验证。运行前请先阅读项目内 `project.json` 与构建配置，核对对应编辑器版本，并使用自己的微信小程序配置。

部分资源引用需在编辑器中检查是否完整；仓库存在不代表当前版本可直接构建。

当前 AI 与测试项目见 [作品集](https://github.com/test123604/ai-project-portfolio)。
